# 🎓 초강스 에듀테크 LAB · 수현T의 주간 AI 미션 통합 아카이브

류용수(룡티) 선생님의 **초강스 에듀테크 LAB** 주간 AI 실전 미션을 아카이빙하고 공유하는 통합 웹 포털입니다.  
매주 새로운 배포 링크를 만들 필요 없이, 하나의 영구 허브 URL과 주차별 디렉터리 구조로 영구 관리됩니다.

## 🚀 무료 웹 배포 방법 (1분 완성)

### 방법 A: Vercel 배포 (가장 빠르고 추천)
1. 터미널 또는 [Vercel 웹사이트](https://vercel.com)에 로그인합니다.
2. 이 프로젝트 폴더를 끌어다 놓거나 GitHub에 푸시 후 연동합니다.
3. 배포 즉시 `https://[프로젝트명].vercel.app` 형태의 고유 링크가 발급됩니다.
   - 메인 허브: `https://[프로젝트명].vercel.app/`
   - 4주차 미션: `https://[프로젝트명].vercel.app/week04/`

### 방법 B: GitHub Pages 배포
1. GitHub에 새 저장소(예: `edutech-missions`)를 만듭니다.
2. 코드를 커밋하고 푸시합니다.
3. 저장소의 **Settings → Pages** 메뉴에서 Source를 `main` 브랜치 `/ (root)`로 선택 후 저장합니다.
4. `https://[아이디].github.io/[저장소명]/`으로 자동 배포됩니다.
