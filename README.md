## 📐 7주차 중수 미션: 조건을 바꾸는 문항 메이커 (이차부등식 3단계 후속 과제)

- **수학 교육과정 성취기준**: 2022 개정 공통수학1 [10공수1-02-11] 이차함수의 부호와 이차부등식의 해 연결 (미분 배제)
  - 서로 다른 두 정수 근 $r < s$ ($-4 \le r < s \le 4$), 최고차항 계수 $a \in \{-3, -2, -1, 1, 2, 3\}$, 부등호 $<, \le, >, \ge$
  - 중근 및 허근 사례는 지원하지 않음을 명시
- **핵심 목표**: 한 문제의 설명을 세 번의 배움(**따라 풀기** → **조건 비교** → **이유 설명**)으로 잇는 학생 맞춤형 후속 과제와 교사용 해설 즉시 생성
- **3대 완료 기준 (Criteria)**:
  1. **두 근・계수・부등호 조절**:
     - $a$, $r$, $s$, 부등호($<, \le, >, \ge$) 실시간 조작 및 수식 갱신
     - $a < 0$ (위로 볼록) 및 $a > 0$ (아래로 볼록) 양방향 포물선 완벽 지원
     - $r < s$ 무결성 보장 슬라이더 연동
  2. **조건 변경 시 답 선택・해설 자동 초기화**:
     - 파라미터 변경 즉시 학생 객관식 답 선택 및 정답 해설 상태를 자동 리셋
     - 리셋 피드백 배너 실시간 안내
  3. **부호와 수직선이 일치하는 계산**:
     - $x < r$, $r < x < s$, $x > s$ 3개 구간의 수치 대입 검산표 ($f(r-1), f((r+s)/2), f(s+1)$) 자동 계산
     - 등호 유무에 따른 열린 점($\circ$) vs 닫힌 점($\bullet$) 및 안쪽/바깥쪽 영역 하이라이트 SVG 렌더링
- **3단계 후속 과제 구성**:
  - **Task 01 · 따라 풀기**: 숫자를 바꾼 유사문제를 풀고 4지선다형 보기 중 선택 후 즉시 해설 확인
  - **Task 02 · 조건 비교**: 등호 유무($\le$ vs $<$)에 따른 영점 포함/제외 차이와 수직선 점 모양 비교
  - **Task 03 · 이유 설명**: 영점을 빠뜨린 대표 오답을 관찰하고 바르게 고쳐 수학적 이유를 서술
- **교구 인터랙션 & 데이터 보안**:
  - 교사용 해설과 학생용 과제 완벽 분리 인쇄 및 저장 (학생용에는 정답·해설·교사 메모 배제)
  - **공통 인쇄 표준 (`window.EdutechPrint`)**: 새로운 탭을 띄우지 않고 인라인 숨김 iframe을 통해 크롬 네이티브 인쇄/PDF 저장 창을 즉시 호출
  - **수학 범위 표기 가독성 표준**: 음수 기호(`-`)와 물결표(`~`)가 겹쳐서 생기는 가독성 저하를 방지하기 위해 표준 부등식 표기(`-3 ≤ a ≤ 3 [a ≠ 0]`, `-4 ≤ r < s ≤ 4`) 또는 명확한 한글(`-3부터 3까지`) 표기 적용
  - 학생 개인정보(이름, 성적, 연락처) 일체 미수집 가이드 준수
  - 외부 AI API 종속성 없는 100% 브라우저 기반 Vanilla JS 엔진
