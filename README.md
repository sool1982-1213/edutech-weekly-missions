# 🎓 초강스 에듀테크 LAB · 수현T의 주간 AI 미션 통합 아카이브

류용수(룡티) 선생님의 **초강스 에듀테크 LAB** 주간 AI 실전 미션을 아카이빙하고 공유하는 통합 웹 포털입니다.  
매주 새로운 배포 링크를 만들 필요 없이, 하나의 영구 허브 URL과 주차별 디렉터리 구조로 영구 관리됩니다.

## 📐 6주차 고수 미션: 15분 두 갈래 수업 설계 (제한된 구간의 이차함수 최대·최소)

- **수학 교육과정 성취기준**: 2022 개정 공통수학1 [10공수1-02-06] 제한된 구간에서 이차함수의 최대·최소 (미분 배제)
- **핵심 목표**: 수업 시작 5분 진단 질문과 보기별 익명 응답을 바탕으로 학급의 이해도를 확인하고, **개념 다지기**와 **적용 확장** 중 알맞은 15분 후속 수업 경로를 교사가 주도적으로 선택·설계
- **3대 완료 기준 (Criteria)**:
  1. **교사가 선택하는 두 가지 수업 경로**:
     - **경로 A · 개념 다지기 (Support)**: 후보 선택·대입·비교 중심 (3분 + 5분 + 5분 + 2분 = 15분)
     - **경로 B · 적용 확장 (Extend)**: 구간 변경 및 꼭짓점 경계 사례 논리 설명 중심 (2분 + 5분 + 5분 + 3분 = 15분)
  2. **합계 15분인 체계적 활동 순서**:
     - 도입(구간 표시 / 근거 공유) → 함께/적용(대입 검산 / 구간 변경) → 짝 설명(값 비교 / 경계 사례) → 출구 질문
  3. **학생용 활동지와 교사용 해설 분리 저장**:
     - **학생용 HTML**: 정답, 해설, 교사 메모, 집계 보드를 완전히 배제하고 손글씨 필기용 빈칸과 깨끗한 SVG 그래프 제공
     - **교사용 HTML**: 정답, 단계별 검산($f(x)$ 대입표), 변경 구간 해설, 교사 메모, 평가 윤리 가이드 포함
- **교구 인터랙션 & 데이터 보안**:
  - $f(x)=a(x-h)^2+k$ 포물선과 닫힌구간 $[left, right]$ 실시간 인터랙티브 SVG 렌더링
  - 꼭짓점 위치 프리셋 3종 ([구간 밖], [구간 안], [구간 경계]) 원클릭 전환 시 자동 리셋
  - 학생 개인정보(이름, 성적, 연락처) 일체 미수집 (오직 보기별 인원수만 집계)
  - 15분 수업안 원클릭 복사 & 수동 복사 대안 지원
