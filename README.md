## 🔢 5주차 중수 미션: 행렬 오답 클리닉 (곱셈 순서 재도전)

- **수학 교육과정 성취기준**: 2022 개정 공통수학1 [10공수1-04-01], [10공수1-04-02]
- **핵심 목표**: 실수의 곱셈처럼 순서를 바꾸는 오류($AB = BA$)를 구체적인 수치 예시로 확인하고, 다른 숫자로 다시 도전하여 곱셈 순서의 원리를 체화
- **3대 완료 기준 (Criteria)**:
  1. **$AB$와 $BA$를 각각 계산한 구체적 수치 예시**: 행렬 $A=\begin{pmatrix}a & b \\ 1 & c\end{pmatrix}$, $B=\begin{pmatrix}1 & 1 \\ 0 & 1\end{pmatrix}$에서 $a, b, c$ 변경 시 실시간 전개
  2. **조건이 다른 재도전 문제와 피드백**: $a', b', c'$가 적용된 새 행렬 곱 $A'B'$ 정답과 역순 계산 $B'A'$ 오답 보기를 비교하고 채점 피드백 제공
  3. **조건 변경 시 힌트·선택·결과 초기화**: 슬라이더 조작 시 이전 오류 선택, 열린 힌트, 풀이 펼침, 재도전 선택을 안전하게 자동 리셋
- **수업 자료 저장 및 출력**:
  - 학생용 활동지 HTML (정답·해설 배제)
  - 교사용 해설지 HTML (정답·성분별 검산·원인·처방·교사 피드백 메모 포함)
  - 설명 카드 텍스트 원클릭 복사 및 브라우저 인쇄/PDF 기능
