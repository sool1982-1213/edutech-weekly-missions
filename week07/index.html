TASK 02 · 조건 비교 등호 하나, 달라지는 해의 영역과 수직선

동일한 이차식에서 부등호의 등호 유무만 바꾸었을 때, 해의 범위와 수직선 표현이 어떻게 달라지는지 비교해 봅니다.

조건 A (현재 설정 식)
(x + 1)(x − 3) ≤ 0
해: −1 ≤ x ≤ 3
등호 포함: 영점 −1, 3 포함 (닫힌 점 ●)
조건 B (등호 반대 식)
(x + 1)(x − 3) < 0
해: −1 < x < 3
등호 제외: 영점 −1, 3 제외 (열린 점 ○)
💡 교사 지도 핵심 원리

두 부등식의 식은 동일하지만 등호의 유무에 따라 영점 x = −1, 3의 포함 여부가 달라집니다. 부등호 밑에 막대기(=) 하나가 붙고 떨어짐에 따라 수직선의 점이 꽉 찬 원(●)과 빈 원(○)으로 달라집니다.

TASK 03 · 이유 설명 틀린 해의 조건을 찾아 바르게 고치고 이유 서술

학생들이 가장 흔하게 범하는 오류 사례를 관찰하고, 빠뜨린 수학적 조건을 찾아 올바르게 교정합니다.

⚠️ 가상 학생의 오답 사례

이차부등식 (x + 1)(x − 3) ≤ 0 의 해를 구하는 과정에서,
어떤 학생이 오답: "−1 < x < 3" 이라고 작성했습니다.

✅ 바른 풀이 및 수학적 이유

바른 해: "−1 ≤ x ≤ 3"

주어진 부등식은 ≤ 0 형태이므로, x = −1 또는 x = 3을 대입했을 때 f(x) = 0이 되어 부등식을 참으로 만듭니다. 따라서 영점을 해의 영역에 반드시 포함해야 합니다.
